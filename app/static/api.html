核心接口

  • GET /healthz：进程健康检查与版本。
  • GET /api/v1/readiness：配置与接入状态，不返回密钥。
  • GET /api/v1/platforms：四套平台规则；对话工作台默认小红书。
  • POST /api/v1/conversations/turn：主入口。多轮对话完成需求澄清、选品确认、图文生成、修改和发布前确认。
  • GET /api/v1/conversations/{session_id}/export?format=markdown：导出已审批且仍绑定当前材料的四部分报告。
  • GET /api/v1/knowledge/connection：当前 ima 知识库连接状态。
  • GET /api/v1/hotspots：可选的公开热榜轻关联参考。

下载 OpenAPI 规范 ↗

请求体 application/json，大小上限 256KB。密钥仅通过服务端环境变量读取，错误响应不回显原始输入或凭证。合规核验是规则扫描，不是逐条语义核验。
