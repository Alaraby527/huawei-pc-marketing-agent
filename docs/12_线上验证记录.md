## 2.1 小红书扫码热点

- 主应用顶栏“连接小红书”弹出二维码；二维码由内部 MCP 服务 `cangyuyi/huawei-xhs-mcp` 生成。
- 用户在手机小红书 App 扫码并授权后，主应用通过 MCP 读取实时笔记标题、链接和互动数，作为热点线索。
- MCP 只作为内部服务：用户入口始终是主应用；`XHS_MCP_BASE` 与 `XHS_MCP_TOKEN` 只存在服务端 Secrets。
- 未登录、MCP 不可用或搜索为空时，自动回退公开热榜/微博/编辑方向。
- 公网演示不要登录个人主账号；登录会话为实例共享，实例重启后失效。

## 2.2 自由输入、逐题补全与六页图片

- 首屏是普通对话框，用户可以直接输入不完整的需求；Agent 理解后只对缺失信息逐题弹出选项卡片，点选后自动进入下一题。
- 选项卡片只在当前问题存在时出现，回答后立即移除；发布确认不再占据输入框上方的长卡片，改为输入框下方的紧凑操作条（通过 / 再短一点 / 换一版 / 刷新材料）。
- 输入区内提供模型下拉，默认显示“默认模型 · qwen-plus”；选项来自 `GET /api/v1/models` 的 `LLM_ALLOWED_MODELS` 白名单，密钥不会下发。另有“规则引擎”和“更多模型（待配置）”占位。
- 内容目标步骤显示动作选项，并在热点数据返回后补充可选热点标签；选择热点会把标题随目标一起提交。
- 助理消息和运行态显示 `skill · 需求解析`、`tool · 官方知识库`、`skill · 候选核验`、`gate · 产品确认`、`skill · 六页方案`、`skill · 合规扫描` 等调用轨迹。
- 预算有限且当前价格未核实时，Agent 不假装推荐成立，而是提供“继续生成型号级附条件稿（不写价格）”或“换一个候选”；附条件稿仍不能声称预算内可买。
- 生成后可下载 `posters.zip`：六页 1080×1440 PNG，使用官方产品图与事实标签；线上实测 ZIP 1.05 MB、本地 1.30 MB，六页均为 1080×1440。
- 线上已走通：需求 → 3 个候选 → 选 1 → 到店体验 → 六页方案 → 通过确认 → 导出；顶栏“连接小红书”可正常弹出二维码。

## 2.3 左侧任务栏、热点搜索与可折叠工作栏

- 左侧栏包含新建任务、热点搜索、自动化/插件市场占位和任务列表；任务记录存本地并用 `GET /api/v1/conversations/{id}/state` 恢复会话。
- 热点搜索是独立视图：展示榜单（小红书实时笔记或明确标注的公开热榜/编辑方向），点热点可“查看热点详情”或“使用热点”；使用热点会把标题和链接带入对话框。
- 右侧工作栏可展开/收起，收起后对话占满剩余宽度；对话区没有常驻遮挡卡片。
- 快捷键：`⌘/Ctrl+N` 新建任务，`⌘/Ctrl+K` 打开热点搜索。
- 线上已验证：左侧任务栏、热点搜索视图、热点详情、使用热点带入对话框、工作栏收起/展开均正常；用“参考热点：开学季…”加想法生成时，草稿开头会引用该热点。
- 本地已验证：新建任务会清空会话但保留任务列表；点击历史任务可恢复候选与选项；工作栏收起后对话自动变宽。

## 3. 复现命令

```bash
# 公开页面（浏览器）
open https://cangyuyi-huawei-pc-marketing-agent.ms.show/

# API（脚本，需要 ModelScope token；不要把 token 写进仓库）
curl -s https://studio-cangyuyi-huawei-pc-marketing-agent.api-inference.modelscope.net/healthz \
  -H "Authorization: Bearer $MODELSCOPE_ACCESS_KEY"
```

完整对话流程按 README 的 `/api/v1/conversations/turn` 示例执行；确认后使用 `GET /api/v1/conversations/{session_id}/export?format=markdown`。

## 4. 当前限制

- **本地官方库导出**：当前线上读取官方知识库 v7 ZIP，覆盖 10 个重点型号与 68 张索引图片；它不是实时 ima 调用，`official_library=false`、`competition_ready=false`。拿到赛事共享库权限后，把 `KB_SOURCE` 切回 `ima` 并设置 `IMA_KB_NAME` 再复验。
- **语义核验**：当前是规则扫描 + 数字可追溯，不是逐句事实蕴含核验。
- **公网安全**：没有内置登录/限流；公开演示可以，生产使用需加网关。
- **热点源**：60s 热榜不稳定，界面会回退为编辑方向，不冒充实时热点。

## 5. 安全

- 仓库已做密钥扫描，没有提交 IMA/LLM/ModelScope 凭证。
- 凭证只存在本机私有环境文件和魔搭 Secrets；部署完成后建议轮换在聊天中出现过的密钥。
- 线上截图只展示界面和公开知识库名称，不包含密钥或完整原文。
