## 2. 复用卡（M1 已锁定）

### R-S19 快图 vue-fabric-editor
- 上游：https://github.com/ikuaitu/vue-fabric-editor ，MIT；公开版为前端编辑器，不含商业版后端与模板资产。
- 接入方式：同源预构建静态资源，FastAPI 在 `/studio` 提供宿主页面；不引入第二套登录。
- 输入/输出：`DesignDocument`（`editor_engine/version + native payload + 语义绑定 sidecar + 资产/字体 manifest + revision hash`）。
- 边界：不复制商业版模板/字体；不承诺 PSD 100% 还原；复杂原生文档不做降维转换。
- 替换路径：若构建不可用，保留 JSON 文档 + 现有 PNG 渲染作为降级，不假称编辑器已就绪。

### R-S03 xiaohongshu-mcp
- 上游：https://github.com/xpzouying/xiaohongshu-mcp ，Apache-2.0；非官方连接器。
- M1 用途：只读研究（搜索/详情）；发布写操作待联调。
- 现状：云端扫码被小红书短信风控挡住；MCP 无提交短信码接口，故写发布不启用。
- 边界：账号会话只在服务端；不向前端/模型暴露凭证；不伪造发布成功。

### R-热点适配（自研）
- 来源：`app/hotspot.py`（60s 小红书/微博）+ 人工材料 + 编辑方向兜底；`HOT_SOURCE=curated` 用于托管环境（网关内容审查可能拒绝社交流内容）。
- 输出：话题、来源类型、观察时间、代表链接、关联人群/情绪、产品结合建议、风险、时间窗；不称“官方实时榜”。

### R-图像通道（2026-10-19 更新）

- **主通道**：独立 OpenAI 兼容图像 API（`IMAGE_API_BASE_URL` / `IMAGE_API_KEY` / `IMAGE_MODEL=qwen-image-3.0-pro`）。图生图通过 `/images/generations` 的 `image` data URL 传入产品原图，实测产品外观保持、场景按提示词替换。
- **13 种风格**：数码手账 / 清爽桌搭 / 轻漫画 / 杂志编辑 / 极简产品 / 未来科技 / 复古胶片 / 手绘说明 / 校园学习 / 居家生活 / 通勤办公 / 节日氛围 / 真实场景摄影；提示词禁止生成任何文字，留白由后期排版叠加。
- **知识库原图**：`source=kb` 直接返回核验过的官方素材，不调用生图模型。
- **兜底**：独立通道未配置时回退 DashScope（wanx2.1-imageedit / 文生图背景 + 原图合成）。

### 旧版 DashScope 图像通道
- 现有：DashScope `wanx2.1-t2i-turbo` 氛围封面。
- M1 规划：百炼 Qwen-Image-Edit 云通道做背景/场景编辑；`rembg`（MIT）作为可选抠图，需单独评测模型许可与边缘质量。
- 不接入：ComfyUI（GPL-3.0）、自部署 Qwen-Image-Edit-2511（无 GPU）。

### R-图表
- Apache ECharts（Apache-2.0）用于运营图表；M1 只建数据合同与空态，不造数。

## 3. M1 数据模型与 API

### 3.1 表（SQLAlchemy，Postgres；测试用 SQLite）

`workspaces`、`workspace_app_settings`、`brief_handoffs`、`brief_snapshots`、`products`、`product_claims`、`assets`、`content_items`、`research_runs`、`source_records`、`trend_selections`、`creative_directions`、`creative_boards`、`preview_candidates`、`design_documents`、`content_revisions`、`approvals`、`jobs`、`audit_logs`、`action_tasks`。

所有业务表带 `workspace_id`；引用对象在服务端校验归属，缺失 scope 默认拒绝。

### 3.2 页面分工

- **工作栏**：平台切换在最上（小红书/公众号/朋友圈/海报），下面是与平台匹配的标签页；不同平台有不同的生成与发布逻辑（规则来自 `PLATFORM_RULES`）。创作、编辑、核验、证据、样稿都在这里。
- **小红书数据运营（工作区视图）**：只放发布后的数据运营与管理——发布记录、运营监控、评论待办、告警、复盘与经验。
- **新建任务对话**：驱动整条链路；模型可以自主调用工具（`/agent/turn`），工具调用轨迹在对话里可见。

### 3.3 API（前缀 `/api/v1/workspaces/{workspace_id}/apps/rednote`）

| 端点 | M1 状态 |
|---|---|
| `GET /capabilities` | 实现：返回能力/未开通原因，不含密钥 |
| `POST /brief-handoffs/consume` | 实现：从现有会话 handoff/draft 生成不可变简报快照 |
| `GET /brief-snapshots/{id}` | 实现 |
| `POST /trend-selections` | 实现：固定热点/场景/利益点/证据快照 |
| `POST /creative-directions` | 实现：6 方向，≥3 表达机制、≥3 视觉家族，严格 Schema |
| `POST /creative-boards` | 实现：最多 3 方向样张比较 |
| `POST /style-preview-jobs` | 实现：调用现有渲染器产出封面/内页样张（PNG 资产） |
| `POST /design-documents`、`PATCH /design-documents/{id}` | 实现：原生 payload + sidecar + 版本；If-Match 防覆盖 |
| `POST /content-items/{id}/review-submissions`、`POST /approvals` | 实现：绑定 revision + manifest hash；变更即失效 |
| `POST /publish-plans`、`/publish-plans/{id}/manual-results` | 实现人工路径；连接器 `execute` 返回待联调 |
| `POST /agent/turn` | 实现：模型自主工具调用循环（有界 6 步，工具白名单，轨迹返回） |
| `GET /publish-plans` | 实现：发布计划与已回填笔记列表 |
| `GET /analytics/overview`、`GET /comments`、`GET /alerts`、`GET /retrospectives` | 建表 + 空态合同；真实数据待 M3 |
| `POST /retrospectives`、`POST /playbooks` | M1 建表；复盘生成待 M3 |

## 5. 运行

```bash
# 本地依赖
docker compose up -d postgres redis
export DATABASE_URL=postgresql+psycopg://rednote:rednote@127.0.0.1:5432/rednote
export REDIS_URL=redis://127.0.0.1:6379/0
python -m app.db init          # 建表（开发/CI）；生产用迁移脚本
uvicorn app.main:app --port 7860
```

没有 `DATABASE_URL` 时，工作区接口返回 `CAPABILITY_DISABLED`，原有对话链路不受影响。
