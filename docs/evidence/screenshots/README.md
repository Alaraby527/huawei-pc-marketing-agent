## 为什么单独标注"历史"

说明书第 1 章自己写着：**"线上实例当前运行的是引导式流程版本，线上截图仅代表 0.16.x 行为"**。
把那张截图当成"当前界面"会给评审错误印象，所以文件名里直接写明版本与状态。

同理，六页图文已在当前版本删除，样稿只能作为历史形态展示。
