# 配置与联调验收

## 配置项

| 配置 | 谁提供 | 何时使用 |
|---|---|---|
| `IMA_OPENAPI_CLIENTID` | 使用同一ima账号加入知识库并获取凭证的人 | 第一部分接入 |
| `IMA_OPENAPI_APIKEY` | 同上 | 第一部分接入，敏感值 |
| `LLM_BASE_URL` | 模型服务配置人 | 第二部分真实生成 |
| `LLM_MODEL` | 模型服务配置人 | 可配置模型标识 |
| `LLM_API_KEY` | 模型服务配置人 | 第二部分调用，敏感值 |

当前底座只报告这些变量是否存在，不会实际使用它们调用服务。模型标识应保持可配置，设置替代配置并定期核对可用性；托管平台与模型服务分别验收。

`.env.example`是名称说明，不含真实密钥；应用不会自动加载本地.env。线上通过平台变量/Secrets注入，本地通过启动环境设置。

## 分四层验收

### A. 部署底座

首页、接口文档、健康检查、材料规范和材料校验可用。当前版本的目标就在这一层。

### B. 外部依赖

云端真实访问指定ima库、读取型号资料、展示对应图片，并完成一次真实模型调用。记录耗时、失败类型与不含密钥的结果摘要。

### C. 完整业务

- 指定产品、人群、场景和平台，输出手册要求的四部分结果。
- 同产品换场景，切入点、卖点顺序与图片方案变化。
- 同任务换平台，结构、语气、图片数量和行动引导变化。
- 追问不完整输入，区分相近型号。
- 缺证不编造、冲突停止并提示人工确认。
- 支持临时修改及复制/导出。
- 产品事实和图片可追溯。

### D. 线上交付

- 两台开发电脑关闭后，线上任务仍能完成。
- 多任务和不同会话的资料、结果不混淆。
- 重启后的任务数据行为符合设计，存储与备份已验证。
- 访问权限满足评审要求；以不含敏感资料的完成版本做公开评审入口。
- 说明书不少于3组真实优秀结果，覆盖至少2类场景和2个平台，标明来源。
- 真实录屏覆盖完整流程及场景/平台变化。

## 如何称呼当前成果

A层通过：可以说“部署底座可用”。

A—D全部通过：才有依据称为“可用于比赛评审的完整线上作品”。

当前没有外部依赖实测与云端运行证据，不能承诺完整作品已经上线。
