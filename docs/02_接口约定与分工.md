# 接口约定与分工

**0.2.0更新：第一部分已实现，当前主入口为`POST /api/v1/guide`。本文件MaterialBundle v1.0继续有效；外层新增策略/风险/状态/选图方案，详见`07_前段交接与使用说明.md`。下文部分“待接入”是0.1.0历史任务说明，实际实现以07文档和代码为准。**

## 1. 统一的数据约定

材料包版本：`1.0`。权威定义为`app/contracts.py`，运行后可从`GET /api/v1/contracts/materials`读取JSON Schema。字段变动先协商，再同时更新双方代码与测试。

输入任务包括：`product_query`、`audience`、`scenario`、`objective`、`platform`、`purchase_stage`、`instructions`。

platform枚举：`xiaohongshu`、`wechat_article`、`moments`、`poster`。

## 2. 材料包

- `request_id`：任务关联标识，真实接入后由任务层生成，不能固定复用。
- `data_mode`：`live`或`development`，开发样例不得伪装真实数据。
- `status`：`ready`、`needs_input`、`conflict`、`unavailable`。
- `product`：产品标识、标准型号、配置和确认状态。
- `facts`：事实编号、产品标识、事实内容、限制条件、来源。
- `images`：图片编号、产品标识、可读取地址、图片说明、型号核实状态、来源。
- `issues`：缺口、冲突与待确认事项。

每个来源包括类型、资料标题、定位信息和支持该说法的证据片段。

开发包见`examples/materials.development.json`。它故意没有真实产品事实和图片，不可用于营销生成。

## 3. 第一部分负责人要做什么

在`app/retrieval.py`实现`retrieve_materials(task)`：

1. 确认ima当前账号与指定知识库权限。
2. 按型号/任务检索；未命中时按手册回退目录。
3. 识别具体产品及配置，整理事实和条件。
4. 获取图片，核实产品关联和访问方式。
5. 返回MaterialBundle，真实标明缺失、冲突和失败。

如通过Node调用官方Skill，需要提供完整脚本/依赖、加入Docker镜像并验证。仅把环境变量填入控制台不足以接通。

可读图片地址应在云端及浏览器实际可用，不能使用开发电脑文件路径、本机localhost或短期失效后无法更新的地址。

## 4. 第二部分负责人要做什么

在`app/content.py`及相关模块实现：

1. 内容目标与平台策略。
2. 依据事实和限制条件生成文案。
3. 从核实图片中选图、编排、说明位置。
4. 检查生成后的事实、图片与营销表达。
5. 对可修复问题修订并复核；冲突时停止输出。
6. 支持换平台、修改、复制和导出。
7. 按手册展示场景判断、知识库依据、图文软文、核验结果。

`app/verification.py`目前只有材料预检查；它不能替代这些生成后核验。

## 5. 整合负责人要做什么

- 将当前`/api/v1/tasks`的待接入分支替换为真实任务编排。
- 为任务生成独立标识，管理进度、结果、错误与会话隔离。
- 根据实际耗时决定后台任务方式与有限的重试/超时。
- 记录可追溯的来源与代码版本，避免在日志泄露凭证或原文。
- 真实通过验收后，才更新readiness里的集成状态；不能仅把布尔值改成true。

## 6. 当前接口状态

| 接口 | 当前行为 |
|---|---|
| GET `/healthz` | 进程健康，不代表业务可用 |
| GET `/api/v1/readiness` | 配置存在状态、业务未完成 |
| GET `/api/v1/platforms` | 四个平台的基础规则 |
| GET `/api/v1/contracts/materials` | 数据约定JSON Schema |
| POST `/api/v1/materials/validate` | 结构与预检查；永不声称可发布 |
| POST `/api/v1/tasks` | 503：真实业务待接入 |

本地联调样例：

```bash
curl -X POST http://127.0.0.1:7860/api/v1/materials/validate -H 'Content-Type: application/json' --data-binary @examples/materials.development.json
```

若两人在同一代码库开发，可直接调用模块函数，不需要让两台电脑永久相互连接。若第一部分已有独立HTTP接口，可在retrieval适配器中转换其返回数据，保持上层约定不变。
