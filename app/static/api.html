核心接口

  • GET /healthz：进程健康检查。
  • GET /api/v1/readiness：配置与接入状态，不返回密钥。
  • GET /api/v1/platforms：平台规则（当前仅启用小红书）。
  • POST /api/v1/conversations/turn：主入口。多轮对话完成需求澄清、选品确认、小红书图文生成、修改和发布前确认。
  • GET /api/v1/conversations/{session_id}/export?format=markdown：导出已通过核验的完整四部分报告。
  • GET /api/v1/knowledge/connection：当前ima知识库连接状态。
  • GET /api/v1/hotspots：可选的公开热榜轻关联参考。

下载 OpenAPI 规范 ↗

请求体 application/json，大小上限256KB。密钥仅通过服务端环境变量读取，错误响应不回显原始输入或凭证。
