# 快图编辑器接入与构建（M2）

本文件记录 vue-fabric-editor（快图，MIT）的同源接入方式、EditorAdapter 契约和许可边界。它是实施说明，不把编辑器能力算作已完成。

## 1. 构建与启用

```bash
scripts/build_studio.sh
```

脚本会：克隆上游 → `pnpm install` → `APP_BASE_PATH=/static/studio/ pnpm build` → 把 `dist/` 复制到 `app/static/studio/` → 删除 `.gz` → **删除上游 bundle 内的商业字体（华康金刚黑、汉体）** → 保留上游 LICENSE。

- 构建产物不入版本库是推荐做法；本仓库 `.gitignore` 默认忽略 `app/static/studio/`，需要发布时由部署流程执行脚本。
- 构建完成后 `/studio` 直接服务 `app/static/studio/index.html`；静态资源走既有 `/static` 挂载，无需第二个站点或第二套登录。
- 未构建时 `/studio` 明确显示“构建未就绪”，工作区仍可用 JSON/PNG 往返，不假装编辑器已接通。

## 2. EditorAdapter 契约（拟定）

| 能力 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `loadDocument` | `DesignDocument` | 画布状态 | 原生 Fabric JSON，不做降维转换 |
| `saveDocument` | 画布状态 + `expected_version` | 新 `DesignDocument` | 版本 +1，`revision_hash` 重算；冲突返回 `STALE_REVISION` |
| `selectLayout` | `layout_id` | 初始文档 | 由 `app/design_library.py` 的 64 个配方生成 |
| `bindFacts` | `fact_ids` / 文案 | sidecar 更新 | 事实绑定进 sidecar，不烘焙进底图 |
| `lockProductLayer` | 图层名 | 锁定状态 | 产品/实拍图层默认锁定，换风格不改外观 |
| `renderPreview` | 文档 | PNG | 服务端 `posters` 渲染兜底，用于列表缩略图 |
| `destroy` | — | — | 释放画布与事件监听 |

## 3. DesignDocument 往返

```json
{
  "engine": "vue-fabric-editor",
  "engine_version": "5.3.0",
  "native_payload": {"version": "5.3.0", "objects": ["…Fabric 对象…"], "background": "#F7F8FA"},
  "sidecar": {"layout_id": "V08-C1", "bindings": {"title": "…"}, "facts": ["F-…"]},
  "manifest": {"assets": [], "fonts": ["Noto Sans SC"], "canvas": {"width": 1080, "height": 1440}},
  "version": 1,
  "revision_hash": "…"
}
```

- 保存复杂原生文档时不转换成简化 Scene；审批绑定 `revision_id + manifest_hash + account_ref + approved_window`。
- 正文、图片、页序、产品、账号或声明项变更即失效；改期超出窗口同样失效。
- 服务端在发布前重查审批与文件哈希，不只依赖数据库里的 `approved=true`。

## 4. 设计库（已实现）

- 16 个视觉家族 × (2 封面 + 2 内页) = 64 个布局配方，见 `app/design_library.py`；每家族至少 3 种结构原型，不是换色。
- API：`GET /design-library/styles`、`GET /design-library/layouts`、`GET /design-library/layouts/{id}/preview.png`、`POST /design-documents/from-layout`、`POST /design-documents/{id}/checks`。
- 设计检查（D10 部分）：画布尺寸、字体登记、文字越界、占位图未替换；错误阻止审批，警告提示人工确认。
- 字体只用 Noto Sans SC / Noto Serif SC；模板资源全部自研，不引入未授权 PSD/贴纸。
