# 初赛要求与两小时执行方案

依据：《华为·产业进阶赛道·赛题手册v4(1)》，共9页。下文“必须”来自手册，“建议”是本团队在不足两小时时间内的取舍，不是新增比赛规定。

## 1. 初赛究竟交什么

| 必交材料 | 具体要求 | 手册页码 |
|---|---|---|
| GitHub链接 | 源码、README、安装与运行方法、依赖说明；不得包含API Key、Client ID或其他密钥 | 2、8 |
| 魔搭链接 | 项目、模型或应用展示页面；与GitHub和说明书信息一致；评审期间可访问 | 2、8 |
| 作品说明书 | 功能讲解、优秀运行结果；初赛至少一组可辨认的真实运行结果。建议补充架构、提示词、ima调用方式、部署步骤、已知限制 | 2、8 |

- **初赛不强制交Demo录屏**，录屏是复赛必交。建议现在保留真实运行截图和输入输出，方便写说明书。
- 所有提交链接在评审期内**无需额外授权即可访问**。手册没有规定初赛说明书的文件格式、页数，也没有在本手册给出具体截止时刻或提交入口，以组委会另行通知为准。
- 不能只交概念、PPT、静态页面，不能拿无关电视项目替代本次作品。
- 不得伪造运行结果、抄袭、隐瞒人工代写。不得把ima直接生成的终稿原样转发，必须体现自研Agent的场景处理、平台策略、编排与核验。
- 初赛是综合审核，没有公布初赛百分制权重，也没有“满足一项即晋级”的规则。

## 2. 解决什么问题，给谁用

**作品定位：帮助华为门店导购和内容运营，将顾客的购机需求转成有产品依据、适配发布平台的营销图文。**

操作者是门店导购/营销人员；内容面向大学新生、职场人士、创作者、家庭购机者或企业采购者。前置导购用于理解需求、识别适合的型号和卖点，为内容创作提供依据。最终交付不能停在“推荐一台电脑”。

业务痛点是资料分散、相近型号易混、卖点脱离场景、各平台表达雷同、图片与产品不一致、价格与宣传承诺无依据。闭环应为：

需求理解 → 平台策略 → ima资料和图片检索 → 事实提取 → 图文编排/生成 → 事实与图片核验 → 合规检查 → 修改和导出。

ima只充当**指定产品事实和图片素材来源**；业务策略、提示词、文案组织与核验由自研Agent负责。允许使用公开大模型，无需训练基础模型。

## 3. 应用场景与平台

手册建议的场景是开学季、职场办公、内容创作、家庭换新、企业采购、门店到访、新品首发、节日营销；这些是建议覆盖范围，手册没有要求初赛把八类全部做完。

| 平台 | 必须有的表达变化 | 图片要求 |
|---|---|---|
| 公众号 | 标题、导语、分段正文、结尾行动引导 | 2–4张，来源和插入位置 |
| 小红书 | 口语化标题、短段落、使用场景、话题标签；不得编造亲身体验 | 3–6张 |
| 门店朋友圈 | 短文案、一个核心卖点、咨询或到店引导 | 1–3张，优先主图与场景图 |
| 门店海报 | 主标题、副标题、不超过3个卖点、有依据的活动说明 | 1张主视觉，不拉伸、不错配型号 |

**更换场景必须改变内容切入点；更换平台必须改变结构、语气、图片数量和行动引导。** 只换平台名称或字数不算完成适配。上述数量是各平台规则，两个平台允许的数量可能重叠，演示换平台时应展示真实策略差异。

## 4. 第四部分作品要求逐项落地

| 手册功能 | 你负责的前段 | 队友负责的后段 | 验收方式 |
|---|---|---|---|
| 账号与知识库 | 检查凭证可用性、找到指定共享库、显示连接状态；不展示完整密钥 | 页面呈现状态 | 真实接口返回与库名；不能拿变量存在代替接入成功 |
| 任务输入 | 产品、人群、场景、渠道；提取问题、购买阶段、目标；缺失时追问 | 接受补充和修改 | 输入“想买轻薄本”必须先澄清 |
| 资料与图片检索 | 按型号调用ima；搜索空则回退目录；提取事实、条件、来源和图片 | 使用交接包，不另造事实与产品图 | 换型号，抽查事实与图片来源 |
| 场景与平台策略 | 输出主要问题、卖点优先级、证据缺口、平台规则 | 落实到标题/结构/语气/CTA/选图 | 同产品换人群/换平台 |
| 图文生成 | 提供已确认产品、允许使用的事实和素材 | 标题、导语、正文、图片及插入位置、引导与标签 | 不只输出推荐清单 |
| 事实核验 | 交接每条事实的证据和适用配置 | 对最终成稿逐项反查事实编号 | 相近型号和无依据参数测试 |
| 合规检查 | 标记缺证价格、补贴、承诺、冲突 | 检查并修正文案；不能靠免责声明保留虚构信息 | “全网最低/保证不卡/补贴2000”等干扰测试 |
| 修改与导出 | 保持同一任务的产品/事实身份；换型号重新检索 | 换平台/改卖点/删减后复核，复制或导出 | 修改一次后检查引用仍正确 |

产品事实准确性、场景理解是复赛各20分；图文生成与图片引用、平台适配、自研Agent与提示词各15分；功能10分、合规安全5分。这是**复赛评分**，可作为现在的开发优先级参考，不应写成初赛评分。

## 5. 电视Copilot怎么迁移

参考仓库：<https://github.com/Alaraby527/tv-buying-copilot>。实际查阅README、`agents/master.py`、`agents/clarify.py`、`core/rag.py`。

| 原有能力 | 本次改造 |
|---|---|
| MasterRouter：商品/优惠/履约/售后/澄清等路由 | 改为需求澄清→产品确认→资料检索→材料复核→内容交接；前段不要带入与赛题无关的电视安装售后流程 |
| ClarifyAgent：预算→尺寸/距离→用途 | 改为目标人群/用途→产品型号与配置→发布平台→内容目标；购买阶段可待确认。预算只有选型时需要，不是每篇营销文案的必填项 |
| Memory：短期槽位 | 保存当前任务和用户已确认的信息；换平台复用产品事实，换型号必须重新取证。MVP可由调用方回传槽位，不必上长期记忆 |
| 本地静态JSON知识库、token overlap检索 | 改为指定ima实时检索+目录回退+原文读取；不能把旧电视数据改名当华为知识库 |
| ProductAgent筛选打分 | 按用户用途解释匹配理由；只在知识库实际候选中选；没有证据的价格不能参与预算筛选 |
| Replanner预算/库存检查 | 改为型号/配置/证据/图片来源检查，缺资料、冲突或身份不明时停止交付 |
| Compliance | 前段检查输入风险，后段检查最终成稿；修复后复核，有上限，失败转人工 |
| trace与评测 | 保留实际步骤、状态和脱敏错误。另建华为场景评测，不能沿用电视项目的92%作为本作成绩 |

无需为赶赛复刻五个Worker或搭建MCP服务。一个可解释、会调用工具、有失败分支的Python工作流足以体现自研Agent设计；重点在真实业务闭环。

## 6. 给队友的最小交接

沿用现有`MaterialBundle v1.0`，不另起一套不兼容字段。详见`07_前段交接与使用说明.md`和`app/contracts.py`。

必须包括：任务上下文、产品身份、可引用事实、可用图片、风险缺口、数据状态。每条事实有ID、原文证据、适用配置/限制和资料定位；每张图有ID、读取地址、产品关联、来源与核实状态。

**队友的“生图”应优先实现ima素材选取、裁切排版、图文卡片或海报合成。手册要求图片来自ima，不能用AI生成的产品外观图替代ima产品图片。** 若想扩展生成背景等功能，应先确认赛事口径；两小时MVP建议只用可追溯的ima素材。

本地原文、知识库文件和受限图片不要提交公开仓库。手册禁止删除、修改或对外传播知识库资料；作品需要的合规引用与展示应遵循举办方权限，不能因此公开镜像整库。运行说明中可展示必要来源定位和最小证据，不公开密钥和内部完整库ID。

## 7. 110分钟并行执行建议

| 时间 | 你 | 队友 | 共同验收 |
|---|---|---|---|
| 0–10分钟 | 配置本机凭证，确认库名、权限与可读取型号 | 确认接口和平台规则；启动应用 | 固定材料包v1.0与一个真实型号 |
| 10–35分钟 | 需求补全、型号确认、ima检索/目录回退/原文和图片读取 | 根据材料包生成四部分结果，落实平台规则 | 一包真实材料能被后段接收 |
| 35–60分钟 | 检查证据、配置、图片可读性和缺口状态 | 最终成稿核验、图片位置、合规修订和导出 | 完成第一条真实端到端任务 |
| 60–80分钟 | 准备换平台、缺失信息、相近型号、无依据价格用例 | 修复生成/排版/修改分支 | 第一组结果与一次换平台对比 |
| 80–100分钟 | 写来源、接入和已知限制 | 补README、魔搭页面和作品说明书的运行截图 | 公共页面、启动方式和截图一致 |
| 100–110分钟 | 检查GitHub内容和密钥 | 检查魔搭可访问及提交材料 | 三项链接均可无额外授权访问 |

优先选择实际检索到、资料齐全的型号，先做职场办公+门店朋友圈（至少1张真实图片即可启动最小图文闭环），随后扩展同产品公众号或小红书。不是要求只做朋友圈：后续换平台需要满足各自图片数量与表达规则。

## 8. 提交前必须看到的真实证据

- [ ] 真实ima连接成功，指定共享知识库可读。
- [ ] 输入具体任务，出现实际检索记录、资料标题、事实与图片来源。
- [ ] 图文包含手册四部分：场景判断 / 知识库依据 / 图文软文 / 核验结果。
- [ ] 初赛说明书至少一组真实运行结果；本地合成测试和开发样例不计。
- [ ] 缺型号会追问，型号/配置冲突会停；无依据价格和权益被删除或提示待确认。
- [ ] 更换平台后结构、语气、配图和CTA有实质区别。
- [ ] 能修改并复制或导出最终结果。
- [ ] 自研系统提示词已提交，含角色、场景、平台、知识库、图片、生成、核验、合规八类模块。
- [ ] GitHub/魔搭/说明书一致且可访问；无密钥、无整库原文、无伪造功能或结果。

复赛额外要求：Demo真实运行录屏；说明书不少于3组优秀结果，覆盖至少2类业务场景和2个平台，标明资料与图片来源。不要把这条误当成初赛的强制3组。
